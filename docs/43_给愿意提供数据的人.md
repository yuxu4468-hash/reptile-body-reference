## 一、我们要什么

**一句话：每只动物、每次测量、一行。**

> ⚠️ **没有数量门槛。** 我们自己的曲线里就有 n<30 的（最小的 n=3），
> 所以「多少只才算够」这句话由我们说不出口 —— **有多少发多少，断断续续的也行**。

最理想的是**同一批动物按时间重复测量**（比如每月一次、持续半年以上）——
这样既能做「体长—体重」，也能做「年龄—体长」。
**年龄写大致即可**，我们不需要精确的孵化日期。

### 需要的字段

| 列名 | 必填 | 说明 | 例子 |
|---|---|---|---|
| `个体编号` | ✅ | **能区分同一只动物**即可（耳号、笼号、你自编的号都行） | A01 |
| `测量日期` | ✅ | 年-月-日 | 2026-03-15 |
| `年龄` | ⭐ 强烈建议 | **有它才能做年龄曲线**。写大致年龄即可（如「约 2 岁」「2024 年入手、当时约半年」）；**不需要精确到孵化日期** | 约 2 岁 |
| `吻肛长_mm` | ✅ * | 见下方「口径怎么量」 | 68.5 |
| `全长_mm` | ⭐ 建议 | **含尾**。和吻肛长**同时量同一只**最好 | 132.0 |
| `体重_g` | ✅ | 见下方 | 14.2 |
| `性别` | 建议 | `雄`/`雌`/`未定`——幼体未定很正常 | 雄 |
| `是否怀卵` | 建议 | `是`/`否`/`未知`。怀卵的雌体明显偏重 | 否 |
| `尾况` | 建议 | `完整`/`再生`/`断尾`。守宫这类尾很粗的物种尤其重要 | 完整 |
| `饲养温度` | 建议 | 一个大致的区间就行 | 26–28℃ |
| `备注` | 可选 | 任何你觉得影响体型的事（换饲料、生病、停食…） | 换粮 |

**\* `吻肛长` 与 `全长` 至少要有一个**，但**两个都有最好**（我们能用同一只动物的两个值算换算比，
这是判断口径是否可靠的关键）。

## 二、口径怎么量（**这一步最容易出错，请务必看**）

### 吻肛长（SVL）—— **不含尾巴**

从**吻端**量到**泄殖腔**（就是尾巴与身体交界的那道横缝）。

> ⚠️ **这是两栖爬行动物学里的通用口径**，文献里绝大多数数据都是这个。
> 它**不包含尾巴**。

### 全长（TL）—— **包含尾巴**

从**吻端**量到**尾尖**。

### 两者差多少？**因物种而异，不能换算！**

| 物种 | 全长 ÷ 吻肛长（大致） |
|---|---|
| 球蟒 | ≈ 1.08 |
| 缅甸蟒 | ≈ 1.14 |
| 束带蛇 | ≈ 1.29–1.34 |
| 六角恐龙 | ≈ 1.95 |

> ⚠️ 所以**千万别只写一个"体长"** —— 我们没法判断那是哪一个，
> 这样的数据只能退回，很可惜。
> **请分两列写**，或者在备注里明确写"这是含尾的"。

### 测量注意

- 用**直尺或游标卡尺**，不要用软尺绕（会偏大）
- 动物**自然舒展**时量，**不要拉直**（拉直会测长）
- 同一次测量，**同一个人、同一把尺**，一致性最好
- 体重用**厨房秤**（精度 0.1 g 或 1 g，看动物大小）
- **喂食前后要统一**（建议都在喂食前称），否则同一只动物会波动

## 附：为什么口径这么较真

我们拒收过的数据里，**最大的一类就是"口径不明"**（占四成以上）。
不是数据不好，是**没法用** —— 同样叫"体长"，含尾和不含尾能差 8% 到 95%。
一旦搞错，用户量了自己家的动物，得到的偏差就全是错的。

所以我们**宁可少收，也不猜**。
